# Summary: 조인스

## Main topic
This document explains the reimbursement rule for **Joins (조인스정®)**, focusing on whether it is covered by insurance within the approved indication range.

## Key finding
- **Joins does not have a separately specified reimbursement standard.**
- When administered **within the approved label/indication scope**, it is **recognized as reimbursable**.
- Reference code: **JNS-HD09-202106-02**

## Core concept
The central idea is that reimbursement for [[concepts/reimbursement-criteria]] depends on whether use stays within the officially approved indication range, rather than on a drug-specific special coverage rule.

## Practical implication
- Check the **approved indication** before prescribing or reviewing claims.
- If use is **within the permitted indication**, reimbursement should generally be accepted.
- If use is **outside the approved indication**, reimbursement status is not supported by this document.

## Document focus
This page is limited to the reimbursement basis for Joins and does not provide dosage, efficacy, or safety details.
